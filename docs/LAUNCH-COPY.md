## 6. Community / Developer Forum Post (Reddit r/webdev, Show HN, Discord, Indie Hackers)

### Title: Show / Share: SaveNexa — A clean, fast, open-source public social media video downloader

Hey everyone,

I wanted to share a project I've been building: **SaveNexa** ([https://save-nexa.vercel.app/](https://save-nexa.vercel.app/)).

### Why build this?
Most web-based video downloaders on the internet are plagued with malicious redirects, aggressive popup traps, and poor mobile UI. I wanted to create a modern, high-performance tool that focuses purely on clean UI, strict SSRF security, and reliable stream resolution for public media.

### Tech Highlights:
- **Next.js App Router + TypeScript**: Fast server rendering, zero hydration overhead for content pages.
- **Provider Adapters**: Modular parsers that resolve CDN endpoints for TikTok (watermark-free), Instagram Reels (audio-merged), Reddit (DASH stream handling), X/Twitter (multi-bitrate selection), Facebook, and Pinterest.
- **Security**: Built-in SSRF defense blocking RFC 1918 private subnets, loopback addresses, and non-whitelisted protocols.
- **Privacy**: No user database, no analytics trackers, no account requirements.

### Live Demo & Links:
- Website: https://save-nexa.vercel.app/
- Guides & Tutorials: https://save-nexa.vercel.app/guides
