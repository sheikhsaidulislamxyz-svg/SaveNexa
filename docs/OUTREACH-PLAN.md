# SaveNexa — Outreach & Authority Building Plan

> **Strategic, ethical, and manual outreach roadmap for building authentic domain authority, editorial mentions, and community presence.**

---

## 1. Outreach Philosophy & Ethical Guidelines

SaveNexa adheres strictly to white-hat, quality-first outreach:
- **Zero Black-Hat / Spam Tactics**: Strictly avoid Private Blog Networks (PBNs), automated link builders, forum/blog comment spam, link exchanges, link farms, and low-quality scraper directories.
- **Value-First Editorial Pitches**: Focus on genuine utility, open-source transparency, technical architecture, and browser-native privacy.
- **Accurate Representation**: No fabricated metrics, no fake review claims, and no exaggerated download statistics.

## 4. Community Engagement Strategy (Manual & Constructive)

1. **Reddit (`r/webdev`, `r/SideProject`, `r/opensource`)**:
   - Share transparent project learnings (challenges with Reddit DASH audio combination, Instagram mobile user agent emulation).
   - Never drop uncontextual links; always provide complete value directly within the post.
2. **Hacker News (Show HN)**:
   - Present the open-source codebase and explain how SaveNexa achieves high-speed client-side downloads without intermediate cloud storage costs.
3. **Stack Overflow / Stack Exchange**:
   - Provide genuine answers to web development questions regarding `Content-Disposition`, MIME header streaming, and Next.js SSRF security, citing the open-source repository where directly applicable.
