## 2. Guardrails Against Keyword Cannibalization

To ensure maximum organic search authority, adhere strictly to these 5 negative constraints:
1. **Never create device-specific tool duplicates**: Always direct iPhone, iPad, Android, Mac, and Windows search intent to the primary platform tool or the `/guides/phone-video-download-guide`.
2. **Never split video vs audio tools into separate pages**: TikTok audio extraction is natively integrated into `/tiktok-video-downloader`. Do not create a standalone `/tiktok-mp3-downloader`.
3. **Never create separate year or quality variants**: Do not create pages like `/tiktok-downloader-2026` or `/1080p-video-downloader`. High-definition output is already highlighted on primary tool landing pages.
4. **Never create doorway city/language pages**: Avoid creating localized doorway pages (`/download-tiktok-uk`, `/download-tiktok-usa`).
5. **Never create separate error-code pages**: All download troubleshooting queries are resolved within `/guides/why-video-downloads-fail`.
